Coming to the Syntax of Java Program:-
======================================

->Inorder to write the java programs first of all we need to create the class and we can create the class by making use of "class" keyword and for every class
thier will be a name,and the class name first letter should be of capital letter because of naming convention,if the class name is having the multiple words
then the attaching word first letter should be capital letter,after sucessful creation of class we need to open the curly braces and in between this curly
braces of the class we has to create the main method,after sucessful creation of main method we need to open the curly braces and in between this curly of the

Coming to the Compilation of Java Program:-
===========================================


->If we write the java programs on text editors then we need to make use of windows command prompt for both compilation as well as execution,but if we
write the java programs on IDE[Integrated Development Environment] this is a place where the compilation is hidden and executes the java program
if we want to compile an execute the java programs written on text editors,then first we need to open the windows command prompt and navigate to the path
where java programs are saved,and for compilation we has to make use of one command like javac programname.java ,here javac stands for java compiler

on enter button then the windows command prompt will shows us the output




Coming to the Execution of Java Program:-
=========================================


->As soon as we done writing the java program,the java program will be given to the java compiler and java compiler will generates a .class file after sucessfull
compilation,inside this .class file thier is a byte code or we can also call it as intermediate level langauge,because it is not either in high level langauge or
machine level langauge so we can call it as intermediate level langauge,and to convert this intermediate level langauge into machine level langauge we has to make
use of one software called as JVM

->JVM stands for java virtual machine,its primary responsibility is to execute the java byte code
->When java source code is compiled,it converts into java byte code,the jvm takes the byte code and executes it on respective operating system
->The important point to remember is that JVM is responsible to execute the java byte code and because different operating systems can have thier own JVM
implementations,java achieves platform independence

->JVM has 3 parts:-
    1]CLSS
    2]Memory Management
    3]Execution Engine

1]CLSS
    ->CLSS stands for class loader subsystem
    ->The main duty of the class loader subsystem is to load the .class files into JVM
    ->After sucessful loading the .class files into JVM it performs verification for vulnerabilities

JVM process the classes in 3 main phases:
    Loading ---> Linking ---> Intialization


2]Memory Management
    
    1]Method Area
        ->static variables,static methods and class meta data
    
    2]Stack Area
        ->Local Variables,Threads and Method calls

    3]Heap Area
        ->Instance Variables and Objects

    4]Program Counters 
        ->Program Counters stores the current and next instructions Threads

    5]Native Method Area
        ->Supports native code written by JNI


3]Execution Engine

    1]Interpreter
        ->Interpreter interpretes the byte code line by line

    2]JIT Compiler
        ->JIT stands for Just In Time
        ->JIT compiler compiles the frequently executed byte code into native code that improves the performance

    3]Automatic Garbage Collection
        ->It manages memory automatically by cleaning up the unused Objects


->The most important thing in java programming is that if we make any changes in the java program,then first of all we has to save it and then compile again to
reflect back those changes


2]Explain features of java programming langauge ?

->Java is having the features like
    
    1]Platform independent : Which means java can run on any operating system,if and only if JVM is installed on top of the operating system.


    2]Object-Oriented Concepts : Since java is object-oriented programming langauge,it is having the object-oriented concepts like 
                                    1]Abstraction
                                    2]Encapsulation
                                    3]Polymorphism
                                    4]Inheritance
    
    3]Strongly typed langauge : Which means it requires the explicit declaration of variable type,it is used to catch the type related errors during the
    compile Time.


    4]Automatic Garbage Collection : It manages memory automatically by cleaning up the unused Objects.


    5]Robust : Java can handle the errors gracefully and keeps running without crashing

    6]Secure : Java is more secured programming langauge compared with other languages
                
                for an example: In c programming langauge thier is a concept called pointers which provide the direct access to the memory address,but in
                java programming langauge thier is no concept called pointers so it is not possible to access directly.

    7]Backward Compatability : Java supports older versions


    8]Multithreading : Concurrent exeuction of several parts of the same program at the same time,this will improve the CPU Utilization.


    9]WORA [Write Once RunAnywhere] : Java program written once can RunAnywhere irrespective of that machine is built upon

        for an example: If i develop a java web application in windows operating system,the same application can also run in other operating systems like UNIX and MAC
        if and only if JVM is installed on top of the operating system,which means here iam writing the java code only once in windows operating system,but the 
        application is running on multiple operating systems ,so that we can say that the supports WORA feature.
